# Volume Dock 1.1 — OnePlus 7T Pro

Control Android nativo que sustituye los botones físicos de volumen averiados mediante un panel flotante.

## Funciones
- Botones + y − sobre las aplicaciones, con interfaz de cápsula.
- Candado central: bloquea o desbloquea el desplazamiento.
- Arrastre libre cuando está desbloqueado y persistencia de posición.
- Foreground service + notificación permanente, START_STICKY.
- Reinicio tras encender el terminal (después del primer desbloqueo) y tras actualizar.
- Permisos guiados: overlay, notificaciones en Android 13+, exclusión del ahorro de batería.
- Detención manual desde Ajustes del teléfono > Aplicaciones > Volume Dock > Forzar detención.
- Sin root, sin accesibilidad y sin permiso de Internet.

## APK
Abre Actions > Compilar APK de Volume Dock > última ejecución correcta.
Descarga el artifact VolumeDock-OnePlus-APK. El ZIP contiene app-debug.apk, firmado para instalación de prueba.
Cada compilación puede llevar firma de depuración distinta: futuras actualizaciones pueden requerir reinstalación.

## Advertencias
El sistema Android y OxygenOS pueden detener servicios en primer plano bajo determinadas circunstancias.
No es posible garantizar persistencia absoluta.
No ha sido verificado físicamente en un OnePlus 7T Pro.
